プライバシーポリシー

最終更新：2026年11月24日。

Mushafuk.online は、マディーナのムスハフをページごとに読むためのサイトです。

サイトは Nibras Code が公開しています。

収集しないもの

アカウントはありません。

氏名、メール、電話、位置情報、連絡先、端末識別子は取得しません。

広告はありません。

お客様のデータを販売せず、広告主とも共有しません。

サイト統計

mushafuk.online では、基本的な訪問統計を記録します。ページの経路、参照元サイト（ある場合）、ページの言語、画面が電話とコンピュータのどちらに近いか、です。

検索を使う場合、サイト改善のため、検索語（最大100文字）と結果件数も記録されることがあります。

これらは Supabase 上の当社自身のデータベースに送られます。読者のプロフィール作成や広告には使いません。

一般のウェブサイトへの通信と同様、サーバーは IP アドレスを見ることがあります。それを身元の特定には使いません。

Android アプリには、この訪問記録は含まれません。

端末に残るもの

言語、文字サイズ、夜間モードはこの端末に残ります。

選択したタフスィール、翻訳、イウラーブ、ガリーブの書はこの端末に残ります。

ブックマークとメモはこの端末にのみ残ります。

サーバーには送られません。

検索

検索は、このサイトにあるクルアーン本文、翻訳、タフスィールだけを見ます。

質問がアゼルバイジャン語、トルコ語、英語、またはロシア語の場合、答えはその言語の翻訳から得られます。

質問は外部のモデルには送られません。

インターネットと誦読

インターネットは、ページ、タフスィール、翻訳、イウラーブ、珍しい語句、音声を開くために使います。

音声は EveryAyah サービスを通じて開きます。

接続は HTTPS です。

この接続から読者のプロフィールは作られません。

Mushafuk の Android アプリ

アプリの Tasheeh（誦読チェック）機能は、マイクボタンを押したときだけマイクを使います。

音声認識は電話本体で行われ、音声がアップロードされたり保存されたりすることはありません。マイクを止めると聴取は終わります。権限は電話の設定からいつでも取り消せます。

音声モデル（約69 MB）は、依頼したときに一度だけ HTTPS で GitHub（raw.githubusercontent.com）から、予備として quran.mushafuk.online からダウンロードされ、アプリの「設定 → Hifz」で削除できます。

タフスィールや翻訳をダウンロードすると、ファイルは HTTPS で nihomaho9-ui.github.io から取得されます。マディーナのページ用フォント（約95 MB）は、HTTPS で jsDelivr または GitHub から一度ダウンロードされ、アプリがオフラインで動くよう端末に残されます。

それらのホストに見えるのは、IP アドレスなどの通常の技術データだけです。当社はそれを受け取らず、あなたに関する情報も送られません。

最後のページ、ブックマーク、設定、ダウンロードしたタフスィールと翻訳、誦読チェックの履歴、音声モデルは端末にのみ残ります。

アプリがマイクの許可を求めるのは、Tasheeh モードで初めてマイクをオンにしたときだけです。カメラ、位置情報、連絡先、ファイルへのアクセスは求めません。

アプリにアカウントはなく、広告も解析もありません。

内容はクルアーンであり、広告はありません。
