# Mushafuk Tərcümə language packs

Gzip JSON packs and `index.json` for the Mushafuk Tərcümə Android app (`com.nibras.tercume`).

These files were added only; they do not change the existing website. Each pack is one translation, downloaded on demand and cached on the device.

Arabic Uthmani text is bundled in the app (Tanzil, CC BY 3.0, unaltered), not in these packs.

`bengali_zakaria` is a snapshot of the King Fahd Complex edition (Dr. Abu Bakr Muhammad Zakaria) from the QuranEnc API, taken because it had already dropped off the public catalogue.
