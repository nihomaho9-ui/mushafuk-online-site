Privasi

Kebijakan privasi

Terakhir diperbarui: 24 November 2026.

Mushafuk.online untuk membaca mushaf Madinah halaman demi halaman.

Situs ini diterbitkan oleh Nibras Code.

Apa yang tidak kami kumpulkan

Tidak ada akun.

Kami tidak mengambil nama, email, telepon, lokasi, kontak, atau identitas perangkat Anda.

Tidak ada iklan.

Kami tidak menjual data Anda dan tidak membagikannya kepada pengiklan.

Statistik situs

Di mushafuk.online, situs mencatat statistik kunjungan dasar: jalur halaman, situs rujukan (jika ada), bahasa halaman, dan apakah layar tampak seperti telepon atau komputer.

Jika Anda menggunakan pencarian, teks pencarian (hingga 100 karakter) dan jumlah hasil juga dapat dicatat, agar situs dapat diperbaiki.

Data ini dikirim ke basis data kami sendiri, yang dihosting oleh Supabase. Data itu tidak digunakan untuk membangun profil pembaca dan tidak digunakan untuk iklan.

Seperti pada setiap permintaan situs web, server mungkin melihat alamat IP Anda. Kami tidak menggunakannya untuk mengidentifikasi Anda.

Aplikasi Android tidak menyertakan pencatatan kunjungan ini.

Apa yang tetap di perangkat

Bahasa, ukuran teks, dan mode malam tetap di perangkat ini.

Tafsir, terjemahan, i‘rab, dan kitab gharib yang Anda pilih tetap di perangkat ini.

Markah buku dan catatan hanya tetap di perangkat ini.

Semuanya tidak dikirim ke server.

Pencarian

Pencarian hanya melihat teks Quran, terjemahan, dan tafsir yang ada di situs ini.

Jika pertanyaan dalam bahasa Azerbaijan, Turki, Inggris, atau Rusia, jawabannya berasal dari terjemahan bahasa itu.

Pertanyaan tidak dikirim ke model di luar.

Internet dan bacaan

Internet digunakan untuk membuka halaman, tafsir, terjemahan, i‘rab, kata-kata langka, dan audio.

Audio dibuka melalui layanan EveryAyah.

Sambungan memakai HTTPS.

Sambungan ini tidak digunakan untuk membangun profil pembaca.

Aplikasi Android Mushafuk

Fitur Tasheeh (pemeriksaan bacaan) di aplikasi memakai mikrofon hanya ketika Anda menekan tombol mikrofon.

Ucapan dikenali di telepon itu sendiri; audio tidak pernah diunggah dan tidak pernah disimpan. Pendengaran berhenti ketika Anda mematikan mikrofon. Anda dapat mencabut izin kapan saja di pengaturan telepon.

Model ucapan (sekitar 69 MB) diunduh sekali melalui HTTPS, hanya ketika Anda memintanya, dari GitHub (raw.githubusercontent.com), atau dari quran.mushafuk.online sebagai cadangan, dan dapat dihapus di aplikasi pada Pengaturan → Hifz.

Ketika Anda mengunduh tafsir atau terjemahan, berkas diambil melalui HTTPS dari nihomaho9-ui.github.io. Font halaman Madinah (sekitar 95 MB) diunduh sekali melalui HTTPS dari jsDelivr atau GitHub, lalu disimpan di perangkat agar aplikasi dapat bekerja luring.

Hanya data teknis biasa (seperti alamat IP) yang terlihat oleh host tersebut; kami tidak menerimanya, dan tidak ada hal tentang Anda yang dikirim.

Halaman terakhir, markah buku, pengaturan, tafsir dan terjemahan yang diunduh, riwayat pemeriksaan bacaan, dan model ucapan hanya tetap di perangkat.

Aplikasi meminta izin mikrofon hanya ketika Anda pertama kali menyalakan mikrofon dalam mode Tasheeh. Aplikasi tidak meminta kamera, lokasi, kontak, atau akses berkas.

Aplikasi tidak memiliki akun, dan tidak ada iklan atau analitik.

Anak-anak

Situs ini untuk segala usia. Kami tidak sengaja mengumpulkan nama atau data kontak anak-anak.

Isinya adalah Quran, dan tidak ada iklan.
