隐私政策

最近更新：2026年11月24日。

Mushafuk.online 用于逐页阅读麦地那穆萨夫（Madinah mushaf）。

本网站由 Nibras Code 发布。

我们不收集的信息

没有账户。

我们不收集您的姓名、电子邮箱、电话、位置、通讯录或设备标识符。

没有广告。

我们不出售您的数据，也不与广告商分享。

网站统计

在 mushafuk.online 上，网站会记录基本访问统计：页面路径、来源网站（如有）、页面语言，以及屏幕更像手机还是电脑。

如果您使用搜索，搜索文本（最多 100 个字符）和结果数量也可能被记录，以便改进网站。

这些数据会发送到我们自己的数据库，由 Supabase 托管。它们不用于建立读者画像，也不用于广告。

与任何网站请求一样，服务器可能会看到您的 IP 地址。我们不会用它来识别您的身份。

Android 应用不包含此项访问记录。

保留在设备上的内容

语言、文字大小和夜间模式保留在本设备上。

您选择的经注、译文、语法分析（i‘rab）和生僻词（gharib）书保留在本设备上。

书签和笔记仅保留在本设备上。

它们不会被发送到服务器。

搜索

搜索只查阅本网站上的古兰经文本、译文和经注。

如果问题是阿塞拜疆语、土耳其语、英语或俄语，答案来自该语言的译文。

问题不会被发送到外部模型。

互联网与诵读

互联网用于打开页面、经注、译文、语法分析、生僻词和音频。

音频通过 EveryAyah 服务打开。

连接使用 HTTPS。

此连接不会被用来建立读者档案。

Mushafuk Android 应用

应用中的 Tasheeh（诵读检查）功能仅在您按下麦克风按钮时使用麦克风。

语音在手机本机识别；音频不会被上传，也不会被存储。停止麦克风后即停止聆听。您可以随时在手机设置中撤回该权限。

语音模型（约 69 MB）仅在您要求时通过 HTTPS 从 GitHub（raw.githubusercontent.com）下载一次，备用地址为 quran.mushafuk.online，并可在应用的“设置 → Hifz”中删除。

下载经注或译文时，文件通过 HTTPS 从 nihomaho9-ui.github.io 获取。麦地那页面字体（约 95 MB）会通过 HTTPS 从 jsDelivr 或 GitHub 下载一次，然后保存在设备上，以便应用离线使用。

这些主机只能看到标准技术数据（例如 IP 地址）；我们不会收到这些数据，也不会发送任何关于您的信息。

上一页、书签、设置、已下载的经注和译文、诵读检查记录以及语音模型仅保留在设备上。

应用仅在您首次在 Tasheeh 模式中打开麦克风时请求麦克风权限。它不请求相机、位置、通讯录或文件访问权限。

应用没有账户，也没有广告或分析功能。

儿童

本网站适合所有年龄。我们不会故意收集儿童的姓名或联系方式。

内容为古兰经，没有广告。
