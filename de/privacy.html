Datenschutzerklärung

Zuletzt aktualisiert: 24. November 2026.

Mushafuk.online dient dem seitenweisen Lesen des Medinenser Mushaf.

Die Website wird von Nibras Code veröffentlicht.

Was wir nicht erheben

Es gibt kein Konto.

Wir erheben nicht Ihren Namen, Ihre E-Mail-Adresse, Telefonnummer, Ihren Standort, Ihre Kontakte oder eine Gerätekennung.

Es gibt keine Werbung.

Wir verkaufen Ihre Daten nicht und geben sie nicht an Werbetreibende weiter.

Website-Statistiken

Auf mushafuk.online zeichnet die Website grundlegende Besuchsstatistiken auf: den Seitenpfad, die verweisende Website (falls vorhanden), die Sprache der Seite und ob der Bildschirm eher einem Telefon oder einem Computer gleicht.

Wenn Sie die Suche nutzen, können der Suchtext (bis zu 100 Zeichen) und die Zahl der Treffer ebenfalls aufgezeichnet werden, damit die Website verbessert werden kann.

Diese Daten werden an unsere eigene, von Supabase gehostete Datenbank gesendet. Sie dienen nicht dazu, ein Profil der lesenden Person zu erstellen, und sie werden nicht für Werbung verwendet.

Wie bei jeder Website-Anfrage kann der Server Ihre IP-Adresse sehen. Wir verwenden sie nicht, um Sie zu identifizieren.

Die Android-App enthält diese Besuchserfassung nicht.

Was auf dem Gerät bleibt

Sprache, Textgröße und Nachtmodus bleiben auf diesem Gerät.

Der von Ihnen gewählte Tafsir, die Übersetzung sowie das I‘rab- und Gharib-Buch bleiben auf diesem Gerät.

Lesezeichen und Notizen bleiben nur auf diesem Gerät.

Sie werden nicht an einen Server gesendet.

Suche

Die Suche betrachtet nur den Korantext, die Übersetzungen und die Tafsire, die auf dieser Website vorliegen.

Ist die Frage auf Aserbaidschanisch, Türkisch, Englisch oder Russisch, kommt die Antwort aus der Übersetzung dieser Sprache.

Die Frage wird nicht an ein externes Modell gesendet.

Internet und Rezitation

Das Internet wird genutzt, um eine Seite, einen Tafsir, eine Übersetzung, I‘rab, seltene Wörter und den Ton zu öffnen.

Der Ton wird über den Dienst EveryAyah geöffnet.

Die Verbindung erfolgt per HTTPS.

Aus dieser Verbindung wird kein Profil der lesenden Person erstellt.

Mushafuk-Android-App

Die Funktion Tasheeh (Rezitationsprüfung) in der App nutzt das Mikrofon nur, wenn Sie die Mikrofontaste drücken.

Die Sprache wird auf dem Telefon selbst erkannt; Ton wird niemals hochgeladen und niemals gespeichert. Das Zuhören endet, wenn Sie das Mikrofon anhalten. Die Berechtigung können Sie jederzeit in den Telefoneinstellungen widerrufen.

Das Sprachmodell (etwa 69 MB) wird einmal über HTTPS heruntergeladen, nur wenn Sie es anfordern, von GitHub (raw.githubusercontent.com) oder hilfsweise von quran.mushafuk.online, und kann in der App unter Einstellungen → Hifz gelöscht werden.

Wenn Sie Tafsir oder Übersetzungen herunterladen, werden die Dateien über HTTPS von nihomaho9-ui.github.io geholt. Die Medinenser Seiten-Schriftarten (etwa 95 MB) werden einmal über HTTPS von jsDelivr oder GitHub heruntergeladen und dann auf dem Gerät behalten, damit die App offline arbeiten kann.

Diesen Hosts sind nur übliche technische Daten (etwa eine IP-Adresse) sichtbar; wir empfangen sie nicht, und es wird nichts über Sie gesendet.

Die letzte Seite, Lesezeichen, Einstellungen, heruntergeladene Tafsire und Übersetzungen, der Verlauf der Rezitationsprüfung und das Sprachmodell bleiben nur auf dem Gerät.

Die App fragt nur dann nach der Mikrofonberechtigung, wenn Sie das Mikrofon im Tasheeh-Modus zum ersten Mal einschalten. Kamera, Standort, Kontakte oder Dateizugriff werden nicht angefragt.

Die App hat kein Konto und weder Werbung noch Analytik.

Kinder

Die Website ist für alle Altersgruppen. Wir erheben wissentlich keine Namen oder Kontaktdaten von Kindern.

Der Inhalt ist der Koran, und es gibt keine Werbung.
